Operating-system dependency
Native account hosting uses operating-system SQLite: winsqlite3 on Windows,
libsqlite3.so.0 on Linux. No SQLite native binary, SQLitePCLRaw,
Microsoft.Data.Sqlite, customer database or production configuration is bundled.
Operators install/update the OS dependency and manage their own account data.

Unity-provided dependencies
Physics, Physics2D, Animation, Audio, IMGUI, JSON serialization and
UnityWebRequest modules are supplied by the customer's Unity installation.
Unity engine, built-in/SRP shaders and publishing-tool binaries are not
redistributed by SocketJack. Samples reference compatible installed shaders;
custom-pipeline users assign their own compatible material.

Excluded components and game assets
NAudio is not included. Voice uses Unity capture/playback plus managed Opus.
No World of Warcraft artwork, fonts, audio, names, UI files or proprietary game
assets are redistributed. MMO presets use first-party UI code and colors.
No third-party hosted account/voice/relay subscription is included or required.
